# SPI Temperature and I2C LCD

STM32F401 embedded project that reads temperature data over SPI and displays values on an I2C LCD.

## Hardware and tools

- STM32F401VB
- SPI temperature sensor
- I2C character LCD
- STM32CubeIDE / GCC ARM toolchain

Open `I2C_lcd_SPI_Temp.ioc` in STM32CubeIDE to review the peripheral and pin configuration, then build and flash the board. Generated files under `Debug/` are excluded from version control.
